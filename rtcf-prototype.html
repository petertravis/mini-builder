Article · Rich text field

A 401(k) is an employer-sponsored retirement savings plan that allows employees to contribute a portion of their pre-tax earnings to a tax-deferred investment account.

Contribution Limits (2026)

The IRS sets annual limits on how much you can contribute. For 2026, the employee contribution limit is $23,500 per year. Employees age 50 or older are eligible for an additional catch-up contribution of $7,500, bringing the annual maximum to $31,000.

Company Match

Meridian Health matches 100% of employee contributions up to 4% of your annual salary. This match vests over a 3-year cliff schedule — you must be employed for three full years before you are eligible to claim the full matched amount.

How to Enroll

New employees are automatically enrolled at a 3% contribution rate after 60 days of employment. You can change your contribution rate, investment allocation, or opt out at any time through the HR portal at hr.meridianhealth.com/benefits.

Overview · Rich text field

Rich Text Custom Fields (RTCFs) extend Asana's custom fields model to support multi-paragraph formatted text content attached to any object (Task, Project, Portfolio).

Current custom field types — text, number, date, people, select, multi-select — are limited to a single value and do not support formatting. Enterprise customers frequently request the ability to attach formatted content to records: technical documentation, creative briefs, editorial notes, and meeting summaries.

RTCFs will be rendered using the existing ProseMirror editor infrastructure. Field values are stored as structured JSON (ProseMirror document format) and serialized to HTML for read-only display contexts.

All RTCF values are scoped to the parent object and are not shared across objects. Comments and inline suggestions are supported in the editor at GA.

Background · Rich text field

Problem Statement

Rich Text Custom Fields (RTCFs) extend Asana's custom fields model to support multi-paragraph formatted text content. Current field types are limited to a single value and do not support formatting.

Enterprise customers frequently request the ability to attach formatted content to records. This spec defines the data model, API contract, editor integration, and permission model for RTCFs across the Asana platform.

Key Design Decisions

RTCFs will be rendered using the existing ProseMirror node types. All standard document nodes are supported: paragraph, heading, bullet list, ordered list, blockquote, code block, and image. Field values are stored as structured JSON.

Requirements · Rich text field

Core Requirements

  • Support all ProseMirror node types (paragraph, heading, lists, blockquote, code, image)
  • Field values must be versioned — every save creates an immutable version accessible via API
  • Comments anchored to specific text ranges within the field value
  • Inline suggestions (Google Docs-style) required at GA for all editor surfaces

API Requirements

  • New rich_text type in the CustomField schema
  • GET /fields/{id}/value returns ProseMirror JSON + HTML + version
  • Full version history via GET /fields/{id}/versions
